# Cognivault

### Intelligent Document Question Answering System using Retrieval-Augmented Generation (RAG)

Cognivault is an AI-powered document question-answering system. Users upload PDF documents, ask questions in natural language, and receive answers generated by a Large Language Model (LLM) that are grounded in the content of those documents.

The project combines semantic search, a vector database, and LLM-based generation, exposed through a FastAPI backend and a Streamlit interface.


## Problem Statement

Searching through large PDF documents manually takes time. Cognivault uses RAG to find the relevant passages and generate answers from the uploaded documents, with page-level source information attached to each retrieved chunk.

- **PyPDF** – PDF text extraction

- **Hugging Face** – Text embeddings
- **ChromaDB** – Vector storage and similarity search
- **Google Gemini** – Answer generation

## Features

- Upload PDF documents through a REST API or the Streamlit interface.
- Extract text from PDFs and split it into chunks.
- Generate embeddings using Hugging Face models.
- Store and search document vectors using ChromaDB.
- Ask questions across all documents or restrict a question to a single document using metadata filtering.
- Generate context-grounded answers using Google Gemini.
- Extract and preserve PDF page-level metadata, and track source information at the chunk level.
- Health check endpoint for monitoring the service.
- Connection-status indicator in the Streamlit sidebar.

## How It Works

1. A PDF is uploaded through the Streamlit UI or the `/documents/upload` endpoint.
2. The backend extracts the text and splits it into chunks, keeping the source filename and page number as metadata.
3. Each chunk is converted into an embedding.
4. Embeddings and metadata are stored in ChromaDB.
5. When a question is asked, it is embedded and the most similar chunks are retrieved. If a document is selected, retrieval is filtered to that document only.
6. The retrieved context is sent to Gemini, which generates an answer grounded in that context.

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/health` | Service health check |
| POST | `/documents/upload` | Upload and index a PDF |
| POST | `/query` | Ask a question, optionally restricted to one document |

Interactive API docs (Swagger UI) are available at `http://127.0.0.1:8000/docs` when the server is running.

Example query request:

```json
{
  "question": "Summarize my professional profile",
  "document_name": "Aditi_Singh_Resume.pdf"
}
```

`document_name` is optional. If omitted, all uploaded documents are searched.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/AditiSingh-08/Cognivault.git
cd Cognivault
```

2. Create a virtual environment:

```bash
py -3.12 -m venv venv
```

3. Activate it (Windows PowerShell):

```powershell
.\venv\Scripts\Activate.ps1
```

4. Install dependencies:

```bash
pip install -r requirements.txt
```

5. Create a `.env` file (copy `.env.example`) and add your Gemini settings:

```env
GOOGLE_API_KEY=your_api_key
GEMINI_MODEL=your_model_name
```

## Running the Application

**1. Start the backend:**

```bash
python -m uvicorn app.main:app --reload
```

The API runs at `http://127.0.0.1:8000`.

**2. Start the frontend (in a second terminal):**

```bash
streamlit run frontend/streamlit_app.py
```

**3. Use the app:** upload a PDF from the sidebar, select it, and ask a question.

## Testing
